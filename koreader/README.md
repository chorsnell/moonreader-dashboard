# Reading dashboard plugin for KOReader

`readingdashboard.koplugin` connects KOReader to your self-hosted reading dashboard. It:

- uploads KOReader's reading statistics and what your book sidecars know (progress, status, highlights);
- brings in what the dashboard knows from Moon+ Reader and other sources (progress, finished status, reading history, highlights);
- optionally makes KOReader feel like your Moon+ Reader setup ("Moon+ feel").

The HTTP contract with the server is in [API.md](API.md).

## Install

**Easiest:** download it from the dashboard's **Admin → Imports → KOReader plugin**. That zip comes
with the dashboard's address filled in; the second link, **With the admin password filled in too**,
also fills in the password, so nothing has to be typed on the e-reader.

1. Unzip it so that the `readingdashboard.koplugin` folder ends up in KOReader's `plugins/` folder
   on the device (e.g. `/mnt/onboard/.adds/koreader/plugins/` on Kobo, `koreader/plugins/` on Kindle).
2. Restart KOReader.

You can also take the zip from the `readingdashboard.koplugin` artifact of the
`koreader-plugin` GitHub Actions workflow, or copy `koreader/readingdashboard.koplugin` from this
repo. Those versions start with no address or password set.

### Pre-filled settings (`defaults.lua`)

The dashboard's download adds a `readingdashboard.koplugin/defaults.lua`:

```lua
return { url = "https://example.duckdns.org/books", token = "…" } -- token is optional
```

When the plugin starts and its own settings have no address (or no password), it copies them from
this file once. Values you set yourself are never overwritten. `defaults.lua` is generated by the
server and is **not** part of this repo: don't commit one (it can hold the admin password).

## Setup

**Tools → Reading dashboard**:

- **Dashboard address**: the address you open the dashboard at, including any sub-path, e.g.
  `https://example.duckdns.org/books`. `https://` is added if you leave it out.
- **Admin password**: the dashboard's `UPLOAD_TOKEN`. It's sent as `X-Upload-Token` and shown masked.

Settings are kept in `settings/readingdashboard.lua` in KOReader's folder.

## What syncs, and when

A sync:

1. Uploads `settings/statistics.sqlite3` (PUT `/api/koreader/stats`) when its size or modification
   time changed since the last successful upload.
2. Sends every book in your KOReader history whose sidecar changed since the last sync (all of them
   the first time) to POST `/api/koreader/books`, 100 at a time: md5, file name, title, authors,
   series, pages, percent, status, and annotations. Books whose files are gone are skipped.

With **Sync automatically** on (the default):

- when Wi-Fi connects (at most every 15 minutes);
- when you close a book, or the device goes to sleep, **only if already online**. The plugin never
  turns Wi-Fi on by itself for an automatic sync;
- when you open a book while online, the plugin asks the dashboard about that book (see below).

**Sync now** (menu or a gesture) turns Wi-Fi on if needed, the same way Progress sync does, and
shows the result. Automatic syncs stay silent; the result of the last one appears under
**Last sync**.

Gesture actions (Settings → Taps and gestures): *Reading dashboard: sync now*, *apply Moon+ feel*,
*restore previous settings*.

## Bringing in Moon+ Reader data

**Bring in what the dashboard knows about this book** (also automatic on opening a book):

- **Progress**: if KOReader has never had a position for this book, it jumps to the dashboard's progress.
- **Status**: if the dashboard says finished and KOReader had no status, the book is marked finished.
- **History**: the book's Moon+ reading days are added to KOReader's reading statistics under the
  book's own statistics entry. Days KOReader already has are skipped. Each day becomes rows starting
  at noon, an hour each at most. Before the first change, the database is copied to
  `statistics.sqlite3.readingdashboard.bak`.
- **Highlights**: highlights are looked up in the book's text and added as normal KOReader
  highlights with their note and date. At most 50 are placed per opening; the rest follow the next
  time. Passages that can't be found are listed in the note of one bookmark on page 1.

Progress, status and history are applied once per book. Highlights are matched by text, so nothing
is added twice.

**Bring in Moon+ history for books not on this device**: asks the dashboard about the books in
your history, then offers to add the reading days of books you read in Moon+ that aren't on this
device. They appear in the statistics as separate books.

**Apply progress and status to books on this device**: checks the books in your history and home
folder (up to 2000). For books KOReader has never opened, it sets the reading position and finished
status. With **Add books to collections by genre** on (the default), matched books are also added
to a collection named after their genre. Books you've already opened in KOReader are left alone,
apart from collections.

**Undo Moon+ history** removes every reading day this plugin added: the separate books and the
days added to your own books.

## Moon+ feel

**Apply Moon+ feel** remembers your current settings and then changes these:

- Page turns: tap the top half to go back, the bottom half to go forward; no page turn animation.
- Night mode on: white text on black. Moon+'s **red text on black can't be shown on an e-ink
  screen**, so night mode is the closest.
- For books opened from now on: small margins, line spacing 110 %, publisher fonts off,
  left-aligned text (style tweak "Left align most text"), no hyphenation.
- While reading:
  - tapping the middle of the screen opens a Moon+-style menu: Contents, Bookmarks, Search, Go to,
    Font & layout, Brightness, Night mode, Book information, Sync now and Full menu…;
  - tapping the top or bottom strip turns pages instead of opening KOReader's menus. Swipe down from
    the top or up from the bottom to open them;
  - on the status bar, tap left for book information, tap right for bookmarks, and long-press left
    for brightness. The middle keeps KOReader's behaviour.

Swiping up and down the left edge already changes brightness in KOReader, so gestures aren't touched.

**Restore my previous settings** puts back exactly what was there before, including settings
that weren't set, and removes the tap areas.

## Limitations

- Highlights are only placed in reflowable books (EPUB, FB2, MOBI, …). In PDFs, CBZ and DjVu they
  go into the note of the page 1 bookmark.
- History of books that aren't on the device is kept as separate books whose md5 is
  `moonplus:<dashboard id>`. If you later add the file, its KOReader statistics start as a separate
  entry.
- History needs KOReader's reading statistics enabled.
- This plugin was built against KOReader's master source and tested with stubs. **It hasn't been
  tested on a real device yet.**

## Development

```sh
luacheck --config koreader/.luacheckrc koreader/readingdashboard.koplugin koreader/spec
luajit koreader/spec/run.lua
```

| File | Purpose |
| --- | --- |
| `main.lua` | Plugin: menu, settings, events, sync, Moon+ actions, Moon+ feel UI |
| `client.lua` | HTTP (JSON POST, streamed PUT) with KOReader's socket timeouts |
| `sidecars.lua` | Builds `/books` payloads from sidecars; change detection; batching |
| `moonplus.lua` | Decides and applies progress, status, history, highlights, collections |
| `history.lua` | Synthetic statistics rows and the SQLite adapter |
| `highlights.lua` | Text normalisation and prefix/suffix matching |
| `feel.lua` | Settings snapshot/apply/restore and touch zone definitions |
